# Viewer model credits

Converted to GLB by `python -m cavesim.subt_import` from the DARPA SubT models that Open Robotics
published on Gazebo Fuel (https://fuel.gazebosim.org/1.0/OpenRobotics/models/<name>).

| File | Fuel model | Licence |
|---|---|---|
| survivor.glb | Rescue Randy Sitting | CC0 1.0 |
| backpack.glb | JanSport Backpack Red | CC0 1.0 |
| phone.glb | Samsung J8 Black | CC0 1.0 |
| helmet.glb | Climbing Helmet With Light | CC BY 4.0, Open Robotics |
| rope.glb | Climbing Rope | CC BY 4.0, Open Robotics |
| base_station.glb | Base Station | CC0 1.0 |

The cave tiles and rock textures of the imported SubT maps (`maps/<world>/`) are by Open Robotics,
CC BY 4.0, from the same source.

The drone model, `drone_3d_model/scene.gltf`, is Sketchfab's "Bionic dragonfly four-axis UAV
aircraft" by boxgizmo (Sketchfab Standard licence, see `drone_3d_model/license.txt`). Without it
drones are drawn as spheres.
